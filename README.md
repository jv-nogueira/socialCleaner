# Instagram Unfollow

Deixar de seguir ou remover seguidores na plataforma do instagram. Não há necessidade de conhecimento em programação para a utilização

## Funcionamento

### Instalação
1. Copiar a pasta do repositório remoto para o repositório local 
(git clone https://github.com/jv-nogueira/instagramUnfollowBot.git)
2. Acessar o navegador e clicar em 'Gerenciar extensões' para habilitar o 'Modo do desenvolvedor'
3. Clicar em 'Carregar sem pacote' e abrir a pasta acima
4. A extensão deve estar habilitada conforme a imagem abaixo

![Visualização no navegador Edge da extensão instagramUnfollow](image/extensaoEdge.png)

### Configuração
1. (opcional) Abra o arquivo (usernames.txt) e crie a lista com os perfis para manter no instagram
2. Atualize a extensão e a página do instagram após qualquer modificação
3. Na aba de perfil do instagram, clicar em 'Seguindo' ou 'Seguidores' (conforme a imagem abaixo)
4. Clique na tecla 'F2' e insira o limite (conforme a imagem abaixo)
5. No próximo pop-up, insira quantos segundos
6. Ao atingir o limite definido ou ao pressionar 'F2' gerará o download do arquivo (unfollowList.txt) com o nome e username dos perfis

Não há necessidade de utilizar o editor, mas o código está aberto para contribuições

Não se esqueça de dar uma estrela ao projeto!

## Observações
 
- Evite deixar de seguir muitos perfis na mesma hora. 
  - No máximo um perfil a cada 60 segundos (60 perfis por hora)
  - No máximo 200 perfis por dia
  - Para saber mais sobre isso clique [aqui](https://portalpopclub.com.br/redes-sociais/limites-instagram-por-dia/) e [aqui](https://www.pathsocial.com/pt/resources/spring-clean-how-many-people-can-you-unfollow-on-instagram/)
- A extensão tem como objetivo diminuir ações manuais. Sem inteções maliciosas
- Mantenha a página do instagram ativa durante o funcionamento
- Configure a economia de energia do seu PC para evitar desligamento por inatividade
- Configure o instagram no idioma Português (Brasil) para o funcionamento correto
- O grupo Meta (facebook, instagram, whatsapp) tem restrições com o uso de bots, então use por conta e risco.
